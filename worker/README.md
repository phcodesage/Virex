# Virex API proxy

A Cloudflare Worker that holds the DeepSeek API key server-side and enforces
plan limits. The macOS app talks to this instead of DeepSeek directly, so the
key never ships inside a binary anyone can inspect.

| Plan | Limit |
|---|---|
| Free | 10 rewrites/day per device |
| Pro | Unlimited |

## Deploy

```bash
cd worker
npx wrangler login                       # one-time, opens a browser

# 1. Create the KV namespace and paste the printed id into wrangler.toml
npx wrangler kv namespace create VIREX_KV

# 2. Store the DeepSeek key as an encrypted secret (never commit it)
npx wrangler secret put DEEPSEEK_API_KEY

# 3. Ship it
npx wrangler deploy
```

Deploy prints your URL, e.g. `https://virex-api.<subdomain>.workers.dev`.
Put that in `src-tauri/src/config.rs` as `API_BASE`, then rebuild the app.

## Endpoints

### `POST /v1/rewrite`
Streams the rewrite back as SSE (a passthrough of DeepSeek's stream).

```
Headers: X-Virex-Device: <uuid>
         Authorization: Bearer <licence>   (optional; Pro)
Body:    { "text": "...", "system": "..." }   // system optional
```

`429` with `{"error":"daily_limit_reached"}` once the free allowance is gone.

### `GET /v1/usage`
What the Settings window shows.

```
Headers: X-Virex-Device: <uuid>
→ { "plan": "free", "used": 3, "limit": 10, "remaining": 7 }
```

## Pro licences (Lemon Squeezy)

Payment and licence issuing are handled by Lemon Squeezy — the Worker only
*verifies* keys, so there are no accounts to build and nothing to issue by hand.

1. Create a Lemon Squeezy store and a **subscription** product at $10/month.
2. On the product, enable **licence keys** (one key per subscription).
3. Copy your store id and product id into `wrangler.toml`
   (`LEMONSQUEEZY_STORE_ID`, `LEMONSQUEEZY_PRODUCT_ID`) so keys minted by other
   LS stores are rejected, then `npx wrangler deploy`.
4. Point the landing page's **Get Pro** button at your LS checkout URL.

Flow: customer subscribes → LS emails them a licence key → they paste it into
Virex's Settings → the Worker validates it against LS and caches the verdict.
Cancelling or refunding deactivates the key at LS; the Worker picks that up
within 12 hours (the positive-cache TTL).

### Comping someone / overriding

Manually issued keys bypass Lemon Squeezy entirely:

```bash
npx wrangler kv key put --binding VIREX_KV "license:VIREX-FRIEND-01" "active" --remote
```

Revoke by deleting that key. To force an immediate re-check of an LS key
(e.g. after a refund), delete its cached verdict:

```bash
npx wrangler kv key delete --binding VIREX_KV "pro:<their-key>" --remote
```

## Cost

Workers' free tier covers 100k requests/day and permits commercial use.
You pay DeepSeek for inference on *all* usage, including free-tier users —
`FREE_DAILY_LIMIT` in `wrangler.toml` is the dial that caps that exposure.

## Abuse notes

Free usage is counted per device id generated by the app. A determined user can
reset it, since the client is open source. That's an accepted trade-off for not
requiring accounts; the daily cap bounds the damage. If abuse shows up, the next
step is requiring a (free) sign-in rather than trusting a device id.
